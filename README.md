An entry for the [One Word From Grandma](https://make.fun/c/u-0xkianno-one-word-from-grandma-f04bed16) bounty on [make.fun](https://make.fun) — entrants send exactly one word: the word their grandma would text about AI. A judge model compares words two at a time, and the funniest, most grandma-like word wins.

## The entry

`main.ts` writes exactly one word to `/output/entry.txt`: the word grandma would text about AI.

**contraption** — the word grandmothers already use for any baffling machine they don't understand. Warm, a little baffled, tied to machines, and funny with no caption needed.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
